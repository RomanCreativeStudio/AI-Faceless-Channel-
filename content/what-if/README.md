# What If?

Hypothetical/speculative content built on real history or technology.

**Required convention:** every piece must clearly separate established fact
from hypothetical inference — e.g. explicit "Known" vs. "Hypothetical"
sections or labels. Speculation must never be presented as verified fact
(`CONSTITUTION.md` rule 4).

schema-validation exercise (see its `AUDIT.md`), not a finished video. No
