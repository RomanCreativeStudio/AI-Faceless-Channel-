# Constitution

Non-negotiable rules for this project. Changes to this file require explicit
human owner approval.

1. **Human authority is final.** The human owner has final say over
   publishing, safety, and any change to system rules (this file and
   `SYSTEM.md`). No process in this repository may override that authority.
2. **No automated publishing authority exists.** Nothing in this system may
   post, upload, or otherwise publish content to any external platform
   without an explicit, per-item human approval step. This applies now and
   continues to apply once automation is eventually introduced.
3. **Four first-class content pillars.** All content belongs to one of:
   - Business Stories / Case Studies
   - History
   - Technology
   - What If?

   No pillar is subordinate to another; each has equal standing in
   planning, structure, and review.
4. **What If? content must separate fact from inference.** Any "What If?"
   piece must clearly distinguish established historical fact from
   hypothetical/speculative reasoning built on top of it (e.g. explicit
   "Known" vs. "Hypothetical" labeling). Speculation must never be
   presented as verified fact.
5. **Content must be sourceable.** History and Business Stories content
   should be traceable to real sources; speculative extensions must be
   clearly flagged as such (see rule 4).
6. **Staged progress.** Work proceeds incrementally: documentation and
   structure before implementation, implementation before automation,
   automation before production/publishing. No stage is skipped.
