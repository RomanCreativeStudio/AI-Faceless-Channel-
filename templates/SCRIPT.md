## What If? fact/hypothesis separation

Required only when `content pillar == what-if`. The script MUST visibly
label which section each beat belongs to — never blend them:

- **KNOWN FACT** — `<established history/technology this piece is built on>`
- **ASSUMPTION** — `<the hypothetical change being introduced>`
- **INFERENCE** — `<what logically follows from KNOWN FACT + ASSUMPTION>`
- **SPECULATION** — `<what is modeled as possible but not confidently establishable>`

The script must never present ASSUMPTION, INFERENCE, or SPECULATION
content as if it were KNOWN FACT (`CONSTITUTION.md` rule 4).
